# Exam AI Online Examination Portal

Open `index.html` in a browser or serve this folder with any static server.

## Included features

- Landing page with student name, subject, exam size, and start action
- Timed 25, 50, and 90 question exams
- General Knowledge, Computer Fundamentals, C Programming, Mathematics, English, and Mixed Subjects
- One-question-at-a-time exam UI with options, palette, review marking, progress, and timer
- Randomized questions and options
- Auto-submit on timeout and anti-cheating tab-switch warnings
- Instant evaluation with score, pass/fail, chart, answer review, and print/PDF output
- Admin panel with question CRUD, CSV import, duration settings, results table
- Leaderboard, dark mode, responsive layout, and certificate generation

## CSV format

```csv
subject,question,optionA,optionB,optionC,optionD,correctOption
Mathematics,What is 2+2?,4,3,5,6,A
```
